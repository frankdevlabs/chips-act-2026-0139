## Assessment

**In scope — confirmed.** The fiche's own interinstitutional data (COM(2026) 504, celex 52026PC0504,
"Chips Act 2.0") matches this repo's `file_id` **2026/0139 (COD)**. The fiche itself states that a
**separate fiche in the same transmission covers CADA** (2026/0138) — the `keep_apart` sibling — so the
two are kept apart correctly; CADA content stays in that repo.

**Playbook correction.** `tracker_issues.py` returned `playbook: council-text`, which is a
mis-classification (there is no Council ST text here). A BNC-fiche is a **national-government position
document** = the `stakeholder-social` playbook's "primary government position → register + commit it"
branch. Handled accordingly: registered + committed under `sources/member-states/`, substance routed to
`docs/member-state-positions.md`, with STATUS.md / TIMELINE.md updates. This matches the issue's own
`affects[]` (`docs/member-state-positions.md`, `STATUS.md`, `TIMELINE.md`) and its `nl` label.

**Substantive, not noise.** The fiche is the Netherlands' formal grondhouding: positive on competence
and subsidiarity, positive-with-caveats on proportionality, broadly supportive on the main lines while
pressing hard on governance (stronger Member-State steering via the ESB), the *domestic-undertaking*
>50% ownership test, the direct Art 19 designation of the open-foundry project, procurement /
'sufficient-risk' obligations and crisis powers. The Netherlands (ASML/NXP, Brainport) is a natural
protagonist on this file, so this is a high-value primary source.
